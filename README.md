EXPLAIN 
The codes work together to create The Community Book Nook website: the four HTML files (index.html, about.html, services.html, and contact.html) create the different pages and contain the headings, paragraphs, buttons, navigation links, images, services and contact form, while the style.css file controls how the website looks. The CSS starts with a reset to remove unwanted default spacing, then sets the fonts, colours, text sizes and general spacing used across the website. Flexbox is used to arrange the navigation bar, while CSS Grid is used to arrange cards and page sections into columns. Buttons, cards, forms and links are styled with backgrounds, borders, shadows and hover effects to make the website more attractive and easier to use. The @media rules create responsive design, meaning the website automatically changes its layout when viewed on tablets and mobile phones; for example, three cards displayed in a row on a desktop can change to two columns on a tablet and one column on a mobile phone. The README.md file explains the project, technologies used, CSS features and changes made for Part 2, while the screenshots folder stores evidence of testing the website on different screen size.

# The Community Book Nook

## 1. Project Description

The Community Book Nook is a community library website.
It provides information about the library, its history,
services, programmes and contact details.

The website aims to make information accessible to
families, students, readers and other community members.
